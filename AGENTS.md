# AGENTS.md

Guidance for AI agents and humans working in this repository.

- Read **`skill.md`** first — it is the operating manual: architecture invariants, Redis key layout,
  commands, code conventions, and gotchas. Treat it as binding.
- Read **`plan.md`** for the master plan + Definition-of-Done status board; update it at milestones.
- Commit at phase/milestone boundaries using the existing `Phase N: ...` style. Repo has no git remote.
